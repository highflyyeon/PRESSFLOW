# PRESSFLOW — 강원사회복지신문 통합 콘텐츠 자동화 플랫폼

내 컴퓨터(Windows·Mac·Linux)에 설치해서 쓰는 프로그램입니다. 모든 자료는 **이 컴퓨터 안에만** 저장되고, 외부로 나가는 통신은 네이버 메일(IMAP)과(선택) AI 교정뿐입니다.

## 0. Windows 설치 파일(권장)
GitHub 저장소의 **Releases** 페이지에서 `PRESSFLOW-Setup-x.y.z.exe`를 받아 실행하면 끝입니다(Python 설치 불필요).
바탕화면 아이콘과 자동 시작이 함께 등록됩니다. 서명이 없는 프로그램이라 파란 "PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
이 경우 자동 업데이트는 새 설치 파일을 내려받아 조용히 설치하는 방식으로 동작합니다.

## 1. 설치 (Python으로 설치할 때, 한 번만)
| 컴퓨터 | 방법 |
|---|---|
| Windows | 압축을 풀고 `install_windows.bat` 더블클릭 |
| Mac | `install_mac.command` 더블클릭 (처음 한 번은 우클릭 → 열기) |
| Linux | 터미널에서 `bash install_linux.sh` |

Python 3.10 이상이 필요합니다(Windows는 없으면 자동 설치를 시도합니다). 설치가 끝나면 바탕화면에 **PRESSFLOW** 아이콘이 생기고, 컴퓨터를 켤 때마다 백그라운드에서 자동으로 시작됩니다.
> 프로그램 폴더는 설치 후 옮기지 마세요(옮겼다면 설치 스크립트를 다시 실행).

## 2. 첫 실행 마법사 (5단계)
1. **관리자 계정** 만들기
2. **네이버 메일 연결** — 보도자료를 받는 메일 주소와 *앱 비밀번호* 입력 후 '연결 테스트'
   - 네이버 메일 → 환경설정 → POP3/IMAP 설정 → **IMAP 사용** 켜기
   - 2단계 인증을 쓰면 네이버 계정 → 보안설정 → 2단계 인증 → **애플리케이션 비밀번호** 발급해서 입력
3. **네이버 블로그 연결** — 블로그 주소(또는 아이디). 기존 글(RSS)로 문체·구성을 분석해 스타일 가이드를 만듭니다
4. **AI 교정(선택)·백업 위치** — Claude API 키는 없어도 됩니다(규칙 기반 교정만 사용). 백업은 **다른 드라이브/외장하드/NAS**를 권장
5. **복구키 저장** — 반드시 따로 보관하세요. 이 컴퓨터가 고장 나면 복구키 없이는 백업 속 비밀번호를 풀 수 없습니다

이후 15분마다 메일을 확인하고, 처음 연결 시에는 최근 7일치를 먼저 가져옵니다.

## 3. 매일 쓰는 흐름
받은 보도자료 → 지역 자동 분류 → 원문 저장 → 맞춤법·띄어쓰기 교정(사실 보존 검증) → 사진 이름 정리 → 블로그 초안 → **담당자 검토·승인** → 게시 도우미 → 발행 주소 기록

## 4. 꼭 알아두세요 (한계)
- **네이버 블로그 완전 자동 발행은 지원하지 않습니다.** 네이버가 글쓰기 API를 닫았기 때문입니다. 대신 '게시 도우미'가 제목·본문 복사, 사진 ZIP, 글쓰기 페이지 열기, 발행 주소 기록을 도와줍니다.
- 15분 자동 수집은 **컴퓨터가 켜져 있을 때만** 동작합니다. 꺼져 있던 시간은 켜면 이어서 따라잡습니다.
- 휴대폰에서는 접속할 수 없습니다(보안을 위해 이 컴퓨터에서만 열림).
- HWP(구형 한글) 일부·스캔 PDF·암호 문서는 글자를 못 읽을 수 있으며, 이 경우 '수동 확인 필요'로 표시됩니다.
- 교정은 숫자·날짜·인용문·기관명을 바꾸지 않도록 검증하며, 불확실하면 **제안**으로만 남깁니다. 발행 전 사람이 확인하세요.

## 5. 데이터와 백업
- 데이터 위치: `내 사용자 폴더/PRESSFLOW` (환경변수 `PRESSFLOW_HOME`으로 변경 가능)
- 자동 백업: 6시간마다 변경 파일, 매일 DB, 매주 전체, 업데이트 전 — 모두 암호화, 30일 이상 보관, 정기 복원 테스트
- 수동: `python pressflow.py backup full` / 복원: `python pressflow.py restore 백업파일 복원폴더 --key 복구키`

## 6. 자동 업데이트
설치된 프로그램이 6시간마다 새 버전을 확인하고, 있으면 **스스로 내려받아 설치하고 다시 시작**합니다. 다시 내려받을 필요가 없습니다.
- 수집·백업 중이 아니고 10분 이상 화면을 쓰지 않을 때만 설치합니다. 설치 전에 데이터를 자동 백업합니다.
- **배포 담당자의 전자서명이 맞는 묶음만** 설치합니다(위조·변조 거부). 새 버전이 시작되지 않으면 이전 버전으로 자동 복귀하고 그 버전은 건너뜁니다.
- 수집한 자료·설정·계정은 업데이트로 바뀌지 않습니다.
- 사용자 화면: 설정 → **업데이트** (현재 버전, 지금 확인, 지금 업데이트, 자동 설치 켜기/끄기, 확인 주소)
- 터미널: `python pressflow.py update`

### 배포 담당자용 (새 버전을 내보내는 방법)
1. **최초 1회** 업데이트를 올려 둘 곳을 정합니다. 웹 주소(예: 공개 GitHub 저장소/사내 웹)나 모두가 접근하는 **공유 폴더·NAS** 모두 가능합니다.
2. `python make_release.py url <그곳의 latest.json 주소>` 로 기록한 뒤 이 설치본을 직원 컴퓨터에 설치합니다(또는 각자 설정 → 업데이트에서 주소 입력).
3. 새 버전을 낼 때마다: `python make_release.py build --bump patch --notes "변경 내용"` → `dist/` 의 **zip과 latest.json 두 파일을 그 위치에 올리면** 끝. 직원 컴퓨터는 알아서 설치합니다.
4. 서명 개인키 `release_private.key` 는 **배포 담당자만, 안전한 곳에** 보관하세요(직원 설치본에는 넣지 마세요). 분실하면 이미 설치된 프로그램에 업데이트를 보낼 수 없습니다.
